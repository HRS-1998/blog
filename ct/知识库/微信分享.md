##微信分享实现基本流程

利用微信JS-SDK，可借助微信可以实现拍照、选图、语音、位置等手机系统的能力，同时可以直接使用微信分享、扫一扫、卡券、支付等微信特有的能力。###步骤一：绑定域名
先登录微信公众平台进入“公众号设置”的“功能设置”里填写“JS接口安全域名”。
备注：登录后可在“开发者中心”查看对应的接口权限。**微信绑定的域名必须是外网域名,**

注意：**微信分享页面的域名，必须与其公众号对应的JS安全域名保持一致（2017年新规）**

###步骤二：引入微信库文件
在需要调用JS接口的页面引入如下JS文件，（支持https）：http://res.wx.qq.com/open/js/jweixin-1.0.0.js ###步骤三：通过config接口注入权限验证配置

```javascript
wx.config({
    debug: true, // 开启调试模式,调用的所有api的返回值会在微信客户端alert出来。
    appId: '', // 必填，公众号的唯一标识
    timestamp: , // 必填，生成签名的时间戳
    nonceStr: '', // 必填，生成签名的随机串
    signature: '',// 必填，签名，见附录1
    jsApiList: [] // 必填，需要使用的JS接口列表，所有JS接口列表见附录2
});
```

####config的配置参数需要后台来完成配置。###步骤四：通过ready接口处理成功验证

```javascript
wx.ready(function(){
  config信息验证正确后会执行ready方法，微信相关接口调用都必须放在config函数之内；
  若在页面加载时就调用相应接口，因为config是微信客户端的异步操作，则需要把相应接口放在ready函数中确保接口能够成功执行；
  若用户触发时调用调用相应接口，则可以直接调用，不需要放在ready函数中。
})
```

####注意上面两点 ##分享接口 ###获取“分享到朋友圈”按钮点击状态及自定义分享内容接口

```javascript
wx.onMenuShareTimeline({
  title: '', // 分享标题
  link: '', // 分享链接
  imgUrl: '', // 分享图标
  success: function () {
    // 用户确认分享后执行的回调函数
  },
  cancel: function () {
    // 用户取消分享后执行的回调函数
  },
});
```

###获取“分享给朋友”按钮点击状态及自定义分享内容接口

```javascript
wx.onMenuShareAppMessage({
  title: '', // 分享标题
  desc: '', // 分享描述
  link: '', // 分享链接
  imgUrl: '', // 分享图标
  type: '', // 分享类型,music、video或link，不填默认为link
  dataUrl: '', // 如果type是music或video，则要提供数据链接，默认为空
  success: function () {
    // 用户确认分享后执行的回调函数
  },
  cancel: function () {
    // 用户取消分享后执行的回调函数
  },
});
```

##微信分享示例

```javascript
function weChat() {
  var href = window.location.href.split('#')[0];
  $.ajax({
    type: 'get',
    url: '/api/accompany/getJsConfig',
    data: { url: href },
    cache: false,
    success: function (res) {
      config(res);
    },
  });
}
function config(res) {
  wx.config({
    debug: false,
    appId: res.Data.Appid,
    timestamp: res.Data.TimeStamp,
    nonceStr: res.Data.NonceStr,
    signature: res.Data.Signature,
    jsApiList: ['checkJsApi', 'onMenuShareTimeline', 'onMenuShareAppMessage'],
  });
  wx.ready(function () {
    wx.onMenuShareAppMessage({
      title: '重要通知：今年过年回家不用抢票了',

      desc: '瓜分500万回家基金，人人有份！',
      success: function () {},
      cancel: function () {},
    });

      title: '重要通知：今年过年回家不用抢票了',
      link: 'http://accompanyact.tcysys.tcy365.com/Static/index.html',
```
