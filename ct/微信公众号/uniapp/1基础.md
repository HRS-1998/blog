## 项目结构配置

4. 目录介绍

#### 1\. 剖析 Uniapp 项目目录结构

- **`pages`目录**：存放应用的各个页面组件，每个页面通常由一个`.vue`文件表示，例如`index.vue`就是首页组件，里面包含页面的 HTML 结构、JavaScript 逻辑以及 CSS 样式代码，遵循 Vue 的单文件组件规范。
- **`static`目录**：用于存放静态资源，如图片、字体文件等，这些资源在项目打包后会原封不动地复制到对应的平台项目中，供页面引用。
- **`components`目录**：用来放置自定义的组件，方便在多个页面中复用组件逻辑和 UI，提高代码的可维护性和开发效率。
- **`utils`目录（可自行创建）**：一般用于存放一些工具函数，如数据处理、接口请求封装等通用的代码逻辑，便于在项目中统一调用。
- **`uni_modules`目录（若使用了插件模块）**：存放通过插件市场安装的 uni-app 模块，每个模块有其独立的功能和代码结构。

#### 2\. 讲解`manifest.json`、`pages.json`、`vue.config.js`等配置文件的功能与配置方法

- **`manifest.json`**：
  - **功能**：是应用的配置文件，用于配置应用的基本信息（如应用名称、应用标识、版本号等）、应用的权限申请（如摄像头、地理位置等权限）、以及各平台的特定配置（如安卓的启动图、iOS 的应用图标等）。
  - **配置方法**：
    - 基本信息配置，在 “基础配置” 栏中填写应用名称、应用描述、版本号等字段，注意版本号要遵循规范，方便后续更新管理。
    - 权限配置，根据应用实际需要使用的功能，在 “App 模块配置” 中勾选相应的权限模块，例如若应用需要获取用户位置信息，就勾选 “定位” 权限，同时在代码中进行相应的权限请求处理。
    - 各平台配置，通过切换不同平台的标签页（如 “Android”、“iOS” 等），可以分别设置对应平台的图标、启动图、配置文件等内容，按照平台要求上传相应的图片资源，并填写相关参数。
- **`pages.json`**：
  - **功能**：主要用于配置应用的页面路由、窗口样式、导航栏样式等页面相关的信息，它决定了应用中各个页面如何组织、呈现以及如何进行页面间的导航。
  - **配置方法**：
    - **页面路由配置**：在 “pages” 数组中列出项目中所有的页面路径，每个元素对应一个页面，顺序决定了页面的初始加载顺序和底部导航栏（如果有）的显示顺序。例如：

json

    {
        "pages": [
            {
                "path": "pages/index/index",
                "style": {}
            },
            {
                "path": "pages/detail/detail",
                "style": {}
            }
        ]
    }

- **窗口样式配置**：通过 “globalStyle” 对象可以设置应用的全局窗口样式，如背景色、字体颜色、导航栏背景色等。例如：

json

    {
        "globalStyle": {
            "navigationBarTextStyle": "black",
            "navigationBarTitleText": "我的应用",
            "navigationBarBackgroundColor": "#F8F8F8",
            "backgroundColor": "#FFFFFF"
        }
    }

- **导航栏样式配置（针对有导航栏的页面）**：在每个页面的 “style” 对象中可以单独设置该页面导航栏的样式，如是否隐藏导航栏、自定义导航栏标题等，例如：
  json

      {
          "pages": [
              {
                  "path": "pages/index/index",
                  "style": {
                      "navigationBarHidden": false,
                      "navigationBarTitleText": "首页"
                  }
              }
          ]
      }

     // 获取位置信息
    uni.getLocation({
      type: 'gcj02',
      success: async (res) => {
        const { latitude, longitude } = res;

        // 使用uni-app的逆地理编码
        uni.request({
          url: 'https://restapi.amap.com/v3/geocode/regeo',
          method: 'GET',
          data: {
            key: '您申请的高德地图key', // 需要替换为实际的高德地图key
            location: `${longitude},${latitude}`,
            extensions: 'base',
            s: 'rsx',
            sdkversion: 'sdkVERSION'
          },
          success: (geoRes: any) => {
            let address = '';
            if (geoRes.data && geoRes.data.regeocode) {
              address = geoRes.data.regeocode.formatted_address || geoRes.data.regeocode.addressComponent.province;
            } else {
              address = `${latitude.toFixed(6)}, ${longitude.toFixed(6)}`;
            }
            // 更新状态
            currentAddress.value = address;
            location.value = { latitude, longitude };
            // 触发事件
            emit('change', address, { latitude, longitude });
          },
          fail: () => {
            const address = `${latitude.toFixed(6)}, ${longitude.toFixed(6)}`;
            currentAddress.value = address;
            location.value = { latitude, longitude };
            emit('change', address, { latitude, longitude });
          },
          complete: () => {
            isLoading.value = false;
          }
        });
      },
      fail: (err) => {
        console.error('获取位置信息失败', err);

  // 使用UniApp的地图选择位置功能
  uni.chooseLocation({
    success: (res) => {
      currentAddress.value = res.name || res.address;
      location.value = {
        latitude: res.latitude,
        longitude: res.longitude
      };
      emit('change', res.name || res.address, location.value);
    },
    fail: (err) => {
      console.error('选择位置失败', err);
      // 未授权的情况
      if (err.errMsg && (err.errMsg.includes('fail auth deny') || err.errMsg.includes('fail authorize'))) {
        uni.showModal({
          title: '权限拒绝',
          content: '请在设置中允许使用位置权限以正常使用地图功能',
          showCancel: true,
          confirmText: '去设置',
          success: (modalRes) => {
            if (modalRes.confirm) {
              // 打开应用设置页面
              uni.openSetting({
                success: (settingRes) => {
                  if (settingRes.authSetting['scope.userLocation']) {
                    // 用户打开了位置权限，重新尝试获取位置
                    chooseLocation();
                  }
                }
              });
            }
          }
        });
      } else {
        uni.showToast({
          title: '选择位置失败',
          icon: 'none'
        });
      }
    }
  })
