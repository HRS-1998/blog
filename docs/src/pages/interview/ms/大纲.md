## 1 算法

### 必刷题库

1. LeetCode Hot100（优先数组、双指针、滑动窗口、链表、二叉树、哈希）
2. 了解：背包问题、常见排序、有向图搜索

### 手写高频

- 数组去重、二分查找、滑动窗口模板

## 2 HTML / 浏览器BOM/DOM

### DOM

1. DOM基础操作：增删改查

3. 事件流：捕获、目标、冒泡；事件委托原理与使用场景

### BOM

1. window 相关尺寸：`offsetHeight`、`clientHeight`、`scrollHeight`、`innerHeight` 的区别

3. 窗口、视口、文档的尺寸差异

### 资源加载

1. `defer` / `async` 的区别，脚本加载执行时机
2. `preload` / `prefetch` / `dns‑prefetch` 资源预加载策略

## 3 JavaScript核心

### 3.1 手写实现（必须能手写）

1. `new` 关键字实现
2. `call / apply / bind` 手写
3. Promise 简易实现，Promise 静态方法 all / race / allSettled / any
4. 组合函数 compose、洋葱模型、array.reduce，响应式
5. 迭代器、生成器 Generator
6. 深浅拷贝（**处理循环引用，使用WeakMap**）
7. 防抖、节流
8. XMLtpRequest，axios拦截器
9. 手写 mini-vue 、mini-webpack、mini-vite、sse

### 3.2 JS核心概念

1. 原型、原型链；构造函数、class与function构造函数差异
2. this指向规则：普通函数、箭头函数、call/bind、对象方法
3. JS事件循环：宏任务、微任务执行顺序；浏览器事件循环 vs Node事件循环
4. 实参、形参；参数合并规则
5. Proxy / Reflect；`WeakMap` / `WeakSet`弱引用特性
6. 数组API：`map`、`set`、`flat`、`flatMap`、`Array.from`、`object.enteries`、`object.keys`
7. base64,arraybuffer,unit8Array

### 3.3 模块体系

1. CommonJS vs ES Module 区别
2. ESM循环导入问题；浏览器ESM与Node ESM差异

### 3.4 Babel & AST

1. AST抽象语法树概念
2. Babel完整编译流程：`parse → transform → generate`
3. plugin 与 preset区别；core‑js、polyfill、runtime的作用与差异
4. 自定义Babel插件开发思路

## 5 浏览器原理、性能、安全

### 5.1 浏览器渲染

1. 浏览器完整渲染流水线：解析HTML → DOM树 → CSSOM树 → Render树 → 布局(回流) → 绘制(重绘) → 合成
2. 回流、重绘、合成层，如何减少回流重绘

### 5.2 浏览器缓存（必问）

1. 强缓存：Cache‑Control、Expires
2. 协商缓存：ETag、Last‑Modified
3. 内存缓存、磁盘缓存、ServiceWorker缓存；缓存失效策略

### 5.3 Core Web Vitals性能指标

- LCP最大内容绘制
- FCP首次内容绘制
- CLS累积布局偏移
- INP交互下一步绘制
  > 每个指标含义、优化手段，Lighthouse工具使用

### 5.4 浏览器安全

1. 同源策略；CORS：简单请求、预检请求options
2. Cookie属性：SameSite、HttpOnly、Secure；跨域Cookie
3. XSS：存储型、反射型、DOM‑XSS；防御手段
4. CSRF攻击原理与防御
5. CSP内容安全策略作用
6. 单点登录，双token 策略

### 5.5 内存泄漏

前端常见内存泄漏场景：

- 全局变量、未解绑定时器、事件监听未销毁
- 闭包持有DOM引用、Canvas资源未释放
  > 排查工具：Chrome Memory面板

### 5.6 跨页面通信

postMessage、BroadcastChannel、storage事件；微前端场景通信

## 18 面试软技能‑项目复盘方法论

1. 项目最大技术难点是什么？有哪些备选方案，为什么选择当前方案？
2. 线上问题如何排查？

5. 跨部门协作遇到冲突如何处理
6. 如果重新做一遍这个项目，你会做哪些改进？
