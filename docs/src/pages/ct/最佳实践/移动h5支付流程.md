## 一、同城游App

### 1.1 h5支付

应用场景 ：如联运手游游戏页-h5支付

流程 ：

![](http://49.235.131.245/blog/images/ct-05.png)

【1】调用客户端打开外部浏览器的方法：

- 非棋牌游戏内嵌的h5页面-示例：` tcy_openBrowser({ url: targetUrl });` (targetUrl为服务端返回的畅唐支付中心h5页面地址，tcy_openBrowser这个方法需要客户端支持)
- 棋牌游戏内嵌的h5页面-示例：`lua://openBrowser?url=' + encodeURIComponent(targetUrl)` (targetUrl为服务端返回的畅唐支付中心h5页面地址，lua://openBrowser 这个方法需要游戏方支持)

【2】调用客户端监听h5切回的方法：（前提：客户端提供该方法）

- 该方法需要和客户端约定方法名。

```js
// 界面切换回h5界面时调用
window.tcy_onResumeCallback = () => {
   //  可以触发订单查询
   .....
};
```

### 1.2 客户端支付

应用场景 ：如联运手游游戏页-客户端支付

流程 ：

![](http://49.235.131.245/blog/images/ct-06.png)

【1】调用客户端提供的支付方法：把服务端处理的创建订单结果参数传入到这个方法中调起第三方支付，同时根据业务需求补充其他参数。

```js
// startPay为客户端提供的支付方法名，根据业务需求需要先和客户端沟通确认方法名；
// params包含：服务端处理的创建订单结果参数、业务需求补充其他参数。
startPay(params).then(res->{
	if(res.Code === 0){
		// 支付成功
		return;
	}
	// 支付失败
})
```

## 三、微信公众号

### 3.1 h5支付

应用场景 ：如联运手游游戏页-h5支付

流程 ：

![](http://49.235.131.245/blog/images/ct-08.png)

微信支付jssdk-关键代码：

```js
import bridgeWx from 'weixin-js-sdk';

// 处理微信h5支付：resData为创建订单接口返回的数据
function handleWxPay(vm, resData) {
  const wxDataObj = JSON.parse(resData.PayInfo.WeiXinOaOrderInfo);

  bridgeWx.ready(function () {
    bridgeWx.chooseWXPay({
      timestamp: wxDataObj.timestamp,
      nonceStr: wxDataObj.nonce_str,
      package: wxDataObj.package,
      paySign: wxDataObj.pay_sign,
      signType: wxDataObj.sign_type,
      success: function (res) {
        // 支付成功后的回调函数
        if (res.errMsg === 'chooseWXPay:ok') {
          vm.$Toast.confirm({
            title: '提示',
            message: '支付成功',
          });
        } else {
          vm.$Toast.text(res.errMsg);
        }
      },
      cancel: function () {
        vm.$Toast.text('支付取消');
        closeOrder(vm);
      },
      fail: function () {
        vm.$Toast.text('支付失败');
      },
      complete: function () {},
    });
  });
}
```
