## 1、资源路径（纯js版本）

```
<script src="//static.tcy365.com/cdn/gray/gray-native.js" type="text/javascript"></script>
```

## 2、资源路径 （jquery版本）

该gray.js脚本已发布到cdn上了，在页面上最底部引入该js脚本即可：

```
<script src="//static.tcy365.com/cdn/gray/gray.js" type="text/javascript"></script>
```

特别说明：确保页面在引入gray.js之前已经引入jquery.js脚本了，如果该页面没有引入jquery.js，可以使用下边的方式，两个js脚本同时引入：

```
<script src="//static.tcy365.com/cdn/jquery/1.7.1/jquery.js" type="text/javascript"></script>
<script src="//static.tcy365.com/cdn/gray/gray.js" type="text/javascript"></script>
```
