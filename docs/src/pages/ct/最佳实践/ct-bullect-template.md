    提示：所有对应文件名称统一为小驼峰式 （aA）；路由名称统一为短横线分隔（a-a）

快捷脚手架命令：`bul-cli init` 选择后台模板（[bul-cli](http://doc.uc108.org:8002/web/#/168/17079 'bul-cli')）

#### 一. 生成 main 页面

命令：`npm run plop main`

| 问答   | 类型 | 内容                 | 作用                                  | 备注                                                                   |
| ------ | ---- | -------------------- | ------------------------------------- | ---------------------------------------------------------------------- | --- |
| 问答一 | 输入 | 页面名称             | 用户页面文件夹，.ts文件名称，路由名称 | 1. 小驼峰式 aA；2.短横杆 - 拼接式 ‘a-a’,页面生成时会自动转换成小驼峰式 |
| 问答二 | 单选 | 请选择Search组件配置 | 确定当前Searc组件的样式               | 当前提供三种选项：无搜索；搜索项小于等于2； 搜索项大于3；              |
| 问答三 | 多选 | 请选择Tool组件配置   | 确定当前Tool组件的功能                |                                                                        |
| 问答四 | 多选 | 请选择Table组件配置  | 确定当前Table组件操作栏中功能         |                                                                        |
| 问答五 | 单选 | 请选择弹出组件类型   | 确定当前弹出组件类型                  | Drawer/Dialog 只有存在需要弹出组件时才会有此问答                       |
| 问答六 | 输入 | 页面标题             | 浏览器页签中页面名字                  | 中文                                                                   |     |

##### 注意点：

###### 初始化生成时 （初始脚手架中会存在一个示例页面，这两点都会存在，用该模板开发前先不要删除）

1. router/index.ts 文件中路由集合内必须存在一个对象值，且格式化
2. config/index.ts 文件中 config 对象内必须现有一个键值，且格式化

##### 修改点：

1. interface.ts 修改对应页面各接口路径
2. config/index.ts 修改对应页面的权限
3. types/\*.d.ts 修改参数ts类型

#### 二. 生成 child 子页面

命令：`npm run plop child`

| 问答   | 类型 | 内容                 | 作用                                       | 备注                                                                   |
| ------ | ---- | -------------------- | ------------------------------------------ | ---------------------------------------------------------------------- | --- |
| 问答一 | 输入 | 主页文件夹名称       | 在资源路径中引用以及插入，在对应路由中插入 | 必须与主页文件夹名字保持一致，小驼峰式                                 |
| 问答二 | 输入 | 页面名称             | 子页面文件夹                               | 1. 小驼峰式 aA；2.短横杆 - 拼接式 ‘a-a’,页面生成时会自动转换成小驼峰式 |
| 问答三 | 单选 | 请选择Search组件配置 | 确定当前Searc组件的样式                    |                                                                        |
| 问答四 | 多选 | 请选择Tool组件配置   | 确定当前Tool组件的功能                     |                                                                        |
| 问答五 | 多选 | 请选择Table组件配置  | 确定当前Table组件操作栏中功能              |                                                                        |     |

##### 注意点：

###### 初始化生成时 （若当前主页面无任何子路由时，需要手动先添加一个任意路由对象）

1. 对应主页面下的 children 集合下必须先存在一个对象，且格式化

##### 修改点：

1. interface.ts 修改对应子页面各接口路径
2. types/\*.d.ts 修改参数ts类型

#### 三. 生成 modal 遮罩页组件

命令：`npm run plop modal`

| 问答   | 类型 | 内容              | 作用                                       | 备注                                   |
| ------ | ---- | ----------------- | ------------------------------------------ | -------------------------------------- | --- |
| 问答一 | 输入 | 主页文件夹名称    | 在资源路径中引用以及插入，在对应路由中插入 | 必须与主页文件夹名字保持一致，小驼峰式 |
| 问答二 | 输入 | 子页文件夹名称    | 子页面文件夹                               | 可为空                                 |
| 问答三 | 单选 | 请选择 modal 类型 | 选择遮罩类型，有 dialog，drawer 两种选项   |                                        |
| 问答四 | 输入 | modal 组件名称    | 组件名称                                   |                                        |
| 问答五 | 输入 | modal 组件标题    | 组件标题                                   |                                        |     |

##### 注意点：

1. 需要手动在父组件引入，手动配置路由或者逻辑显示
