
### 不定宽高

#### 1、弹性盒子法

```js
<div class="wrapper2">
  <div class="wrapperContent2">
    <span class="content2">测试</span>
  </div>
</div>
```

```js
.wrapper1 {
  display: flex;
  align-items: center;
  justify-content: center;
  width: 100%;
  height: 400px;
  background-color: black;
}

.wrapper1 .content1 {
  padding: 20px;
  background-color: orange;
}

优点：设置父元素即可，布局灵活，代码简洁，实现复杂布局和自适应布局时比较高效，而且以后代码的可维护性也比较强。
缺点：flex布局有一定的兼容性
```

#### 2、table

```js
<div class="wrapper2">
  <div class="wrapperContent2">
    <span class="content2">测试</span>
  </div>
</div>
```

```js
.wrapper2 {
  *position: relative;
  display: table;
  background-color: black;
  width: 100%;
  height: 400px;
  overflow: hidden;
  text-align: center;
}

.wrapper2 .wrapperContent2 {
  vertical-align: middle;
  display: table-cell;
  *position: absolute;
  *top: 50%;
}

.wrapper2 .wrapperContent2 .content2 {
  display: inline-block;
  *zoom:1;
  *display: inline;
  padding: 20px;
  background-color: orange;
  *position: relative;
  *top: -50%;
}

优点：兼容性好，ie7+
```

#### 3、transform + 定位

```js
html
<div class="wrapper4">
	<span class="content4">22222</span>
</div>
```

```js
.wrapper4 {
  width: 100%;
  height: 400px;
  background-color: black;
  position: relative;
}
.wrapper4 .content4 {
  position: absolute;
  background-color: orange;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}

缺点：transform有一定的兼容性
```

#### 4、网格布局

```js
html
 <div class="wrapper6">
 	<span class="content6">22222</span>
</div>
```

```js
.wrapper6 {
  display: grid;
  align-items: center;
  justify-content: center;
  width: 100%;
  height: 400px;
  background-color: black;
}

  padding: 20px;

优点：设置父元素即可，布局灵活，代码简洁，实现复杂布局和自适应布局时比较高效，而且以后代码的可维护性也比较强。
缺点：grid布局兼容性不好
```

### 不定宽，固定高

#### 1、弹性盒子法 + auto

```js
<div class="wrapper3">
  <div class="content3">测试</div>
</div>
```

```js
.wrapper3 {
  display: flex;
  width: 100%;
  height: 400px;
  background-color: black;
}

.wrapper3 .content3 {
  padding: 20px;
  margin: auto;
  background-color: orange;
  height: 100px;
  line-height: 100px;
}

缺点：有兼容性ie10+
```

### 固定宽，固定高

#### 1、absolute + 四个方向的值相等

```js
<div class="wrapper3">
  <div class="content3">测试</div>
</div>
```

```js
.wrapper5 {
  width: 100%;
  height: 400px;
  background-color: black;
  position: relative;
}

.wrapper5 .content5 {
  width: 172px;
  height: 20px;
  margin: auto;
  position: absolute;
  text-align: center;
  top: 0;
  left: 0;
  right: 0;
  bottom: 0;
  background-color: orange;
}

这种方法一般用于弹出层，需要设置弹出层的宽高。
```

#### 2、absolute + 负边距

```js
<div class="wrapper8">
  <div class="content8"></div>
</div>
```

```js
.wrapper8 {
  width: 100%;
  height: 400px;
  background-color: black;
  position: relative;
}

.wrapper8 .content8 {
  height: 100px;
  width: 100px;
  position: absolute;
  background-color: orange;
  left: 50%;
  top: 50%;
  margin-left: -50px;
  margin-top: -50px;
}
```

### 其他

#### 1、::after

```js
<div class="wrapper7">
	<img src="./1.jpg">
</div>
```

```js
.wrapper7 {
  width: 100%;
  height: 400px;
  background-color: black;
  text-align: center;
}

.wrapper7::after {
  content: '';
  display: inline-block;
  vertical-align: middle;
  height: 100%;
}

.wrapper7 > img {
  vertical-align: middle;
}

这种方法可用于图片居中。
```

#### 2、::before

```js
<div class="wrapper9">
	<img src="./1.jpg">
</div>
```

```js
.wrapper9 {
  width: 100%;
  height: 400px;
  background-color: black;
  text-align: center;
  font-size: 0;
}

.wrapper9::before {
  display: inline-block;
  vertical-align: middle;
  font-size: 14px;
  content: '';
  height: 100%;
}

.wrapper9 > img {
  vertical-align: middle;
  font-size: 14px;
}

这种方法可用于图片居中。
```
