## 1.开发背景

微信开发中JS-SDK的调用（自定义分享）需要基于对应公众号的安全域名，支付调用需要处在对应的支付目录中。安全域名和支付目录各自最多只能绑定三个，无法满足项目开发的需求。

## 2.开发要求

要求实现一个"壳"页面，放在安全域名和支付目录下，通过iframe加载对应的项目地址；
可以做到所有微信相关的功能在壳页面中实现，项目页面通过iframe跨域通信向壳页面中提供必要的数据；

## 3.微信公共页面意义

解决项目域名与安全域名冲突的问题，项目开发中仅需要调用既定接口就可以实现微信网页开发的相关功能；
包括：

- 自定义分享；
- 调起微信支付；
- 微信网页授权（获取用户信息）；
- 其他微信相关功能；

### 5.2 TCYWXPAYSDK API

---

#### TCYWXPAYSDK.redirectUrl

**接口说明：**
TCYWXPAYSDK.redirectUrl(string)
驱动页面跳转至对应的网址

**参数说明：**
网址

**示例代码：**

```javascript
TCYWXPAYSDK.redirectUrl('http://www.baidu.com');
```

---

#### TCYWXPAYSDK.reFresh

**接口说明：**
TCYWXPAYSDK.reFresh()
刷新页面

**参数说明：**
无

**示例代码：**

```javascript
TCYWXPAYSDK.redirectUrl();
```

---

#### TCYWXPAYSDK.share

**接口说明：**
TCYWXPAYSDK.share(object)
设置自定义分享数据

**参数说明：**
数据对象，包括各种自定的分享的各种参数；

```javascript
        {
            title: '',
            desc: '',
            imgUrl: '',
            href: ''
        };
```

**示例代码：**

```javascript
var shareData = {
  title: '子页面自定义标题',
  desc: '子页面自定义简介',
  imgUrl:
    'https://static.tcy365.com/mct/action/tcy365-actspt/assets/img/weixin-share.jpg',
  href: 'http://activitysupport.tcysys.uc108.net/Static/SpecialAct/Common/test/weixin/shell/parent.html?redirect=http%3A%2F%2Fwww.baidu.com',
};
TCYWXPAYSDK.share(shareData);
```

---

#### TCYWXPAYSDK.pay

**接口说明：**
TCYWXPAYSDK.pay(object,function)
调用支付接口，接收支付结果回调

**参数说明：**
object：支付相关参数；

```javascript
 		{
            app_id: 100001,
            order_no: '2419180815487753286272',
            return_url: 'http://paygateinner.uc108.com/return.aspx',
            notify_url: 'http://www.google.com/',
            back_url: 'http://paygateinner.uc108.com/back.aspx',
            operation_code: 'submit_pay',
            timestamp: 1534311180,
            version: 1,
            sign: '44e191d120191af3cc5bc7b93cddcd12'
        };
```

function：支付结果的回调函数；

**示例代码：**

```javascript
var testData = {
  app_id: 100001,
  order_no: '2419180815487753286272',
  return_url: 'http://paygateinner.uc108.com/return.aspx',
  notify_url: 'http://www.google.com/',
  back_url: 'http://paygateinner.uc108.com/back.aspx',

  version: 1,

};
TCYWXPAYSDK.pay(testData, function (d) {
  alert(d.act);
});
```

#### TCYWXPAYSDK.getParentUrl

**接口说明：**
TCYWXPAYSDK.getParentUrl(function)
获取外部嵌套页面当前的url地址参数；

**参数说明：**
function：获取网址成功后的回调

**示例代码：**

```javascript
TCYWXPAYSDK.getParentUrl(function (d) {
  console.log('获取父级页面url', d);
});
```

### 5.3壳页面开发说明

- 页面位置

```javascript
//g.tcy365.com/parent.html
```

- 网址参数

| 参数        | 作用                                             | 要求                       | 注释 |
| :---------- | :----------------------------------------------- | :------------------------- | ---- |
| redirect    | 检测有此参数，页面立即跳转至对应的页面地址；     | encodeURIComponent编码参数 | -    |
| iframe      | 检测有此参数，页面通过iframe加载的方式加载该网址 | encodeURIComponent编码参数 | -    |
| wxopenid    | 微信用户openid                                   | encodeURIComponent编码参数 | -    |
| wxnickname  | 微信用户昵称                                     | encodeURIComponent编码参数 | -    |
| wxavatar    | 微信用户头像                                     | encodeURIComponent编码参数 | -    |
| tcyid       | 同城游userid                                     | encodeURIComponent编码参数 | -    |
| tcynickname | 同城游用户昵称                                   | encodeURIComponent编码参数 | -    |
| tcyavatar   | 同城游用户头像                                   | encodeURIComponent编码参数 | -    |
| ext         | 随机数，放在参数最末                             | encodeURIComponent编码参数 | -    |
| 其他参数    | 视项目情况来设置                                 | encodeURIComponent编码参数 | -    |
