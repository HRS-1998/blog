## 介绍

该文件针对前后端接口给出了约定，减少不必要的合作障碍。

## 1. 通用

### 1.1. 响应数据格式

接口包含处理状态、消息提示（可选）、数据（可选）

```
{
   Code: 0,
   Message: "ok",
   Data: [
       {
           StrData: "b1",
           StrData2: "b2"
       },
       {
           StrData: "b1",
           StrData2: "b2"
       }
   ]
}

```

- Code(int): 自定义状态 0表示成功

- Message: 提示内容

- Data: 显示具体数据 可以是数组或者是对象

#### 特别说明

Message仅供信息参考使用，在实际页面交互中不得使用Message。

前端需根据Code判断并给出产品定义的提示信息。此时前端需自行维护一份Code和Message的字典。

### 1.2. 默认值

当响应体中的某些字段值不存在或没有值时，对其默认值的设定。

number : 0 //没有默认值 可不传此参数

string : ''

array : []

object : {}

阿里巴巴 《Java开发手册》第十章《前后端规约》明确规定：
【强制】前后端数据列表相关的接口返回，如果为空，则返回空数组[]或空集合{}。

### 1.3. 接口路径

接口的路径以'/api/'开头

### 1.4 传递参数

**接口header 传递参数 必须对字段进行编码 防止特殊字符无法传递**

### 1.5 响应标头

`Content-Type:application/json;charset=UTF-8`
请带好 charset

## 3. 数据格式

### 3.1. 时间格式

请求或响应中日期/时间类的字段使用毫秒级时间戳

#### 3.2. 地区源数据

前后端的数据与公司系统保持统一

#### 3.3. 地区字符串的格式

数据遵循“最简原则”。

举例：当用户选择了一个省，那么传输中仅需要传输该省份对应的信息，而非其子地区的罗列

#### 3.4. 表单提交时的前后空格去除

前端负责文本内容的空格去除（当策划文档中规定需做处理时）

## 4. 命名

### 4.1. 命名规范

使用首字母大写驼峰进行命名

### 4.2. 命名拼写

命名中含有错误单词时，请双方及时修正

### 4.3. 命名含义

当字段的含义发生变化，且该项目未上线或已知该字段没有被其他系统使用，请前后端及时修改其命名

## 5. 接口文档配合

### 5.1. 接口文档约定

前端制定一份接口文档，由前后端共同来完善，如不能达成一致请由上级来制定，文档修改统一由前端进行维护。

## 6. 接口建议

### 6.1. 字段要求

在非公共接口的情况下，减少多余字段的返回。

### 6.2. 数据要求

在非公共接口的情况下，减少多余数据的返回。

## 7. 后端管理权限控制

**该条目适用于公司内部系统**

### 7.1. 权限的控制方案

#### 优先使用接口级权限控制，便于前后端代码分离；

**方案：**

第一步：通过接口的方式给出当前用户的权限，如页面查看权限、页面编辑权限等

第二步：前端使用上一步返回的用户权限进行页面渲染

注：该方案用于在前后端分离的基础上做权限控制，请后端开发者依然在接口上做权限校验。

#### 当必须使用页面级权限控制时，使用后端技术进行权限控制；

**方案：**

如在mvc的控制层做处理，此时前端配合将页面转为cshtml

### 7.2. 接口权限

当接口有权限控制功能时，使用http的特定状态码通知前端，以便前端页面的合理提示

有权限（即正常访问）：HTTP状态码 200；

未登录：HTTP状态码 401;

已登录但无权限：HTTP状态码 403；

## 8 常用规范

### 8.1 分页

**注意：当最后一页内容为空时 服务端返回上一页内容**

格式如下

```
Data: {

    PageIndex:1,//页号
    PageSize:20,//页长
    PageCount:200,//总页数
    RecordCount:4000,//总记录数
    List:[{}]

}

```

### 8.2 数据中字典

**注意：内容中存在字典时 需要内容时请把字典内容返回**

格式如下

```
Data: {
    List:[
		{
			Name:'小明',
			ClassID:1,	//字典id
			ClassName:'4班'	//字典name
		}
	]
}
```

### excel 导出（toc推荐使用）

接口返回下载地址的形式进行下载 不要使用文件流 这样无法知道下载状态

```
Data: {
    Url:'xxx.com'
}
```
