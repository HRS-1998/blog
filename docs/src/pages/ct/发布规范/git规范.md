## tag规则

x.x.x

第1位：大版本号

第2位：增加新特性

第3位：bug修复

## tag管理

### 有产品项目版本号

1. 打的tag跟项目版本号一致 3 位

如：1.1.0 日志：新功能xxx

2. 修复bug项目版本号不升级 那用 4 位

如：1.1.1 日志：修复bugxxx

### 没有产品与项目版本号

每次打tag请使用 [版本] + 日志说明 的方式

例如：

1.0.1 日志：修复xxxbug

**上传打包后的文件 如 dist static**

## 分支命名

master 主分支 只放置正式版

release-x.x.x 开发分支

hotfix-x.x.x 紧急修复分支

## git工作流程

新建git项目
克隆到本地
新建开发分支
发正式版时打tag合并回主分支

## 合并主分支

切换到主分支 选择 squash 模式 不要带分支记录

## 忽略文件

- 不要上传psd prd文档 zip压缩包 exe文件

- 在需要创建 .gitignore 文件的文件夹, 右键选择Git Bash 进入命令行，进入项目所在目录。

- 输入 touch .gitignore 在文件夹就生成了一个“.gitignore”文件。

- 然后在”.gitignore” 文件里输入你要忽略的文件夹及其文件就可以了。
