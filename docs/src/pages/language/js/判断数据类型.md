# JS 判断变量类型 4 种方法（前端面试高频）

## 1. typeof （最常用，基础类型）

> 适合：`string / number / boolean / undefined / symbol / bigint / function`

```
typeof 'abc'      // 'string'
typeof 123        // 'number'
typeof true       // 'boolean'
typeof undefined  // 'undefined'
typeof Symbol()   // 'symbol'
typeof 123n       // 'bigint'
typeof function(){} // 'function'

// ❌ 坑
typeof null       // 'object' 历史bug！
typeof []         // 'object'
typeof {}         // 'object'
typeof new Date() // 'object'
```

**缺点**：无法区分 数组、普通对象、null、日期、正则，全都返回`object`

## 2. Array.isArray () 专门判断数组

```
Array.isArray([]) // true
Array.isArray({}) // false
```

## 3. Object.prototype.toString.call (变量) ✅【精准万能方法】

> 返回格式 `[object 类型名]`，可以区分几乎所有内置类型

```
Object.prototype.toString.call('')      // "[object String]"
Object.prototype.toString.call(1)       // "[object Number]"
Object.prototype.toString.call(true)    // "[object Boolean]"
Object.prototype.toString.call(null)    // "[object Null]"
Object.prototype.toString.call(undefined) // "[object Undefined]"
Object.prototype.toString.call([])      // "[object Array]"
Object.prototype.toString.call({})      // "[object Object]"
Object.prototype.toString.call(new Date()) // "[object Date]"
Object.prototype.toString.call(/reg/)  // "[object RegExp]"
Object.prototype.toString.call(new Map()) // "[object Map]"
Object.prototype.toString.call(new Set()) // "[object Set]"
```

封装成工具函数：

```
function getType(v) {
  return Object.prototype.toString.call(v).slice(8, -1)
}
getType([]) // 'Array'
getType(null) // 'Null'
```

## 4. instanceof 判断**引用类型实例**（原型链）

> 判断 `构造函数.prototype` 是否在实例原型链上

```
[] instanceof Array // true
{} instanceof Object // true
new Date() instanceof Date // true

// ❌ 坑1：跨iframe失效（不同window，Array构造函数不是同一个）
// ❌ 坑2：基本类型不行
'abc' instanceof String // false
// ❌ 坑3：可以手动修改原型，结果不可靠
```

# 选型总结（直接背）

1. 原始类型（除 null）→ `typeof`
2. 判断数组 → `Array.isArray()`
3. 需要精准区分所有内置类型 → `Object.prototype.toString.call()`
4. 判断自定义类实例 → `instanceof`
