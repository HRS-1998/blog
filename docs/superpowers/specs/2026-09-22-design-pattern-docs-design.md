# 设计模式文档模块 — 设计文档

日期：2026-09-22

## 目标

在 `docs/src/pages/designPattern/` 下为常见 14 种前端设计模式各建一个 Markdown 文档，详细说明模式并举例其在前端的应用，同时配置 VitePress 侧边栏菜单。

## 范围

覆盖《JavaScript设计模式与开发实践》的 14 种模式：

单例、策略、代理、迭代器、发布-订阅、中介者、状态、命令、组合、模板方法、享元、职责链、装饰者、适配器。

外观模式、工厂模式作为"相关模式"附在适配器、单例篇末尾，不单独建文件。

命名风格：数字前缀 + 中文名，与题库（`01-js.md`）、数据结构（`链表.md`）模块一致。

## 每篇文档统一结构

1. 一句话定义 + 解决的核心问题
2. 结构说明（文字描述角色与关系）
3. 原生 JS/TS 实现（现代 class 语法）
4. 前端真实应用场景 2-3 个（框架源码/组件级举例）
5. 优缺点 + 与易混淆模式的对比

各模式的前端应用场景示例：

| 模式 | 应用场景 |
|------|---------|
| 单例 | 全局弹窗/Loading、Vuex store、ES Module 天然单例 |
| 策略 | 表单校验、动画缓动函数、消除 if-else 分支 |
| 代理 | 图片懒加载、Vue3 Proxy 响应式、缓存代理 |
| 迭代器 | for...of、Symbol.iterator、Generator |
| 发布-订阅 | EventBus、Node EventEmitter、Vue 事件总线 |
| 中介者 | 聊天室、vuex/redux 全局状态、antd Form |
| 状态 | 红绿灯、Promise 状态机、订单状态流转 |
| 命令 | 撤销/重做、宏命令、GUI 按钮 |
| 组合 | DOM 树、Vue 组件树、文件目录 |
| 模板方法 | 生命周期钩子、框架初始化流程 |
| 享元 | 对象池、React/Vue 列表 key 复用、虚拟列表 |
| 职责链 | axios 拦截器、Redux 中间件、事件冒泡 |
| 装饰者 | HOC 高阶组件、ES7 装饰器、权限校验嵌套 |
| 适配器 | 接口适配、旧接口兼容、参数转换 |
